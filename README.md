# Siap Tempur

Siap Tempur is a Next.js learning platform for CPNS/SKD preparation. The app focuses on practice workflows, structured learning content, test readiness, and Supabase-backed product features.

## Highlights

- CPNS/SKD preparation platform
- Practice and assessment-oriented user flows
- Modern Next.js app structure with tests and automation scripts
- Supabase-backed features and deployment configuration
- Production domain: `siaptempur.id`

## Tech Stack

- Next.js
- TypeScript
- Supabase
- Playwright
- Tailwind CSS / PostCSS

## Repository Structure

- `app/` — Next.js app routes and pages
- `components/` — reusable UI components
- `lib/` — shared utilities and service logic
- `supabase/` — Supabase configuration and database-related assets
- `tests/` and `playwright/` — automated test coverage
- `docs/` — project documentation
- `scripts/` — operational and developer scripts

## Development

```bash
npm install
npm run dev
```

Run the available project checks from `package.json` before deploying.
